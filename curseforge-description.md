# Character Select

Terraria-style character slots for NeoForge 1.21.1. Your character — nickname, skin, gamemode, and everything it carries — is separate from the worlds you play it in.

## Features

- **Character slots** with nickname, skin (Mojang lookup, PNG upload, or your own account skin), and a rotating paper doll preview
- **Permanent gamemode per character.** Survival characters can never reach creative or spectator. Which worlds a character can enter is configurable (strict separation by default)
- **Optional hardcore characters** that end for good on death
- **Cheat tracking.** A survival character that enters a world with cheats is marked, keeps a restorable pre-cheat snapshot, and can be refused by worlds that require a clean character
- **Servers act like vanilla.** On someone else's server your character is cosmetic only — the server keeps owning your actual data
- **Curios support** built in, plus an API for other mods to declare their own data
- **Safe to add to existing worlds/packs** — pre-existing saves stay open to every character and are inherited automatically, nothing is lost

## Notes

- Fully configurable — every gate above can be loosened or turned off
